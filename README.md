# Tuna HR
## About
Originally created for 2026 Terricon Valley Hackathon, it was later forked by me, one of the team members of our team in that hackathon.  
Tuna HR is a next-gen digital HR platform that can understand natural language as well as old-fashioned commands.
* The main advantage of this project are "Fish coins", a virtual currency that motivates employees and can be used to buy merch or additional vacation period.
* 

## Project stack
* n8n as a no-code AI automation platform, combining LLM, RAG, and a backend.
* Telegram as an interface to this digital HR
* HTML, CSS and JavaScript for landing website

## Usage
Import all `.json` files into n8n, connect Telegram Bot API and (optionally) host a landing website.
Then you can use Tuna HR through Telegram, using your bot whose API key was used.
